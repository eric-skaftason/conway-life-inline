An implementation of Conway's Game of Life.  It includes play/pause functionality as well as 5 speed settings.  

The idea of this project is that the entire website is contained in a data URI under 3 KB.

Compilation prerequisites:
- NodeJS

Compilation:
- Open a terminal in the root project directory
- Run `node build.mjs`
- The resultant URI will be stored in a text file: dist/uri.txt

The URI may be pasted into a browser's address bar to run the project.
